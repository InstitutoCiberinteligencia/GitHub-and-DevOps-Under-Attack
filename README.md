# GitHub and DevOps Under Attack: A DFIR Perspective

Interactive companion reference for the Ekoparty 2026 talk (BlueSpace) by
Pablo Araya del Pino and Natalia Bravo.

Triage guide, GitHub vs Azure DevOps logging matrix, attack chains, a supply-chain
campaign timeline (Shai-Hulud, Miasma, Hades, TeamPCP and the August 2026 arrests),
a DFIR checklist and a source list.

## Use
Open `index.html` in a browser. It is a single self-contained file: no build step,
no external scripts, no analytics. Checklist progress is stored only in your browser.
