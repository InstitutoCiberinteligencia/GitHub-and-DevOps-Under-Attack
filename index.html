Collect before you need it. Streaming and extended retention must exist before the compromise; enabling them afterwards cannot reconstruct telemetry that was never collected.
Cost note. Turning auditing on is separate from the cost of the destination: Azure Monitor ingestion and retention, SIEM licensing, and storage for exported logs can all be billable. Check current pricing for your subscription.

04

Supply-chain campaigns

How attacks on CI/CD and developer ecosystems evolved. Each entry cites its sources; where vendors disagree on details, both are linked.

Latest · verified Oct 8, 2026. On Aug 26, 2026 Australian police, with the FBI, arrested and charged two men (21 and 23) accused of being TeamPCP members. Charges are allegations and the figures below are police estimates. Since March, TeamPCP and copycats have moved from poisoned scanners and Actions to self-spreading worms that abuse trusted publishing, so a valid provenance attestation no longer proves a package is clean. Jump to the arrests ↓
Names differ by vendor. Microsoft and Unit 42 use Miasma for the June 1 Red Hat wave (after the “Miasma: The Spreading Blight” repositories it creates). Socket and The Hacker News call the June PyPI branch Hades. Microsoft, Wiz and Tenable call the broader 2026 activity Mini Shai-Hulud. Zscaler ThreatLabz applies Miasma (March) and Hades (May to June) to earlier waves. Attribution to TeamPCP is a vendor or law-enforcement allegation depending on the incident, and the worm’s source code has been public since May 12, 2026.
Commits made through the API. Microsoft documents Miasma injecting .github/setup.js into non-protected branches of victim repositories through the Git Data API, with the message “chore: update dependencies [skip ci]” and a spoofed github-actions author. The Git database endpoints can create a tree, a commit and move a reference without a local clone, so a commit that does not trace back to a workstation should be correlated with the token in the audit log.
